# WEBSITE SISTEM OTOT (MUSKULAR) — GITHUB PAGES

## Upload ke GitHub
1. Buat repository baru.
2. Upload `index.html`.
3. Upload folder `assets` BESERTA seluruh folder `images` di dalamnya.
4. Buka Settings → Pages.
5. Pada Build and deployment pilih **Deploy from a branch**.
6. Pilih branch **main** dan folder **/(root)**.
7. Save.

Website akan mendapat link GitHub Pages setelah proses deployment selesai.

Catatan: CSS dan JavaScript sudah menyatu di dalam `index.html`, jadi tidak ada file CSS atau JS terpisah.
